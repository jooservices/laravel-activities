# Governance

## Project model

`jooservices/laravel-activities` is an owner-driven project. JOOservices maintains
the package; the project owner holds final decision authority.

## Roles

| Role | Holder | Responsibility |
| --- | --- | --- |
| Owner / lead maintainer | Viet Vu (JOOservices) | Roadmap, architecture, release approval |
| Maintainers | Appointed by the owner | Review PRs, keep CI green |
| Contributors | Everyone else | Propose changes via issues and PRs |

## Decision making

- Day-to-day changes merge through PR review
- **Releases require explicit owner approval**
- Breaking changes are acceptable only in major versions

## Quality authority

Pint `per`, PHPCS, PHPStan/Larastan, PHPMD, PHP-CS-Fixer, format sanity, the
coverage floor, and required CI may only be relaxed by the owner.

## Conduct

Code of Conduct reports go to [admin@jooservices.com](mailto:admin@jooservices.com).
